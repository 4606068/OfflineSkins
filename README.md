# OfflineSkins (1.21.11 port)

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md)

> This is a fork of [zlainsama/OfflineSkins](https://github.com/zlainsama/OfflineSkins), updated and ported to Minecraft **1.21.11**. The original author's latest supported version is 1.21.5.

## What's different in this fork
- Ported to Minecraft **1.21.11**
- Codebase otherwise unchanged from upstream

## About the mod
This mod allows you to show off your skins even if the server is in offline mode.

## Installation
1. Download the `.jar` from [Releases](../../releases)
2. Place it in your mods folder
3. Launch the game
