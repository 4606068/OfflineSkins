# OfflineSkins (порт под 1.21.11)

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md)

> Это форк мода [zlainsama/OfflineSkins](https://github.com/zlainsama/OfflineSkins), обновлённый и портированный под Minecraft **1.21.11**. Последняя поддерживаемая автором версия — 1.21.5.

## Что изменено в этом форке
- Порт под Minecraft **1.21.11**
- Остальной код не менялся относительно оригинала

## О моде
Мод позволяет отображать ваш скин, даже если сервер работает в offline-режиме.

## Установка
1. Скачайте `.jar` из [Releases](../../releases)
2. Поместите в папку `mods`
3. Запустите игру

## Благодарности
Весь оригинальный код и идея принадлежат [zlainsama](https://github.com/zlainsama), автору OfflineSkins. Этот форк лишь добавляет поддержку новой версии Minecraft.
